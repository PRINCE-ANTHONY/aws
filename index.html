04 / A few good questions

Start where
you are.

No prior cloud experience required. Bring curiosity, a laptop, and an appetite for building real solutions.

What is the AWS Student Builder Group?
An officially recognized, student-led campus cloud community. We focus on hands-on infrastructure, AWS cloud workshops, hackathons, and preparing students for in-demand cloud engineering roles.
Do I need previous AWS or cloud experience to join?
None at all! We start with foundational principles (Compute, Storage, Networking, Identity) and build up to multi-service event-driven serverless architectures step-by-step.
Will attending cost me any money on AWS?
Zero dollars. All workshops are carefully architected to operate 100% inside the AWS Free Tier (Lambda, S3, DynamoDB, API Gateway). For deeper architectures and Bedrock LLM labs, we supply free AWS Educate / sandbox credits.
What should I bring to build nights?
Bring your laptop, a charger, and your curiosity! We recommend installing Node.js, the AWS CLI, and VS Code beforehand, but mentors will be on-site to help you get everything configured in minutes.
Can this help me earn AWS Certifications?
Yes! We provide structured study groups, practice exam vouchers, and architecture deep dives for both AWS Certified Cloud Practitioner (CCP) and Solutions Architect Associate (SAA).
